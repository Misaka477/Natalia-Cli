# Natalia 类型参考 — v1

> 本文档是 `docs/api-reference.md` 的配套：api-reference 描述协议面（路由、
> 鉴权、事件、失败分类、SDK 方法表），本文档给出所有结果类型的**完整字段
> 形状**——嵌套对象以路径展开（`obj.field`、`arr[].field`、`?.field`），因此
> 无需阅读 `@natalia/contracts` 源码即可知道每个返回值的形状。
>
> 文末"机器派生"标题下的表格由源码表生成（`npm run docs:api-reference`），
> 与英文版逐字节一致；防漂移守卫（`packages/transport/test/api-reference.test.ts`）
> 在二者不一致或与代码不一致时使门禁变红。

## 1. 怎么用

1. 在 api-reference 的 SDK 方法表中找到成员的返回类型名（如
   `RuntimeCheckpoint[]`、`CheckpointPreview`）。
2. 在下方表格中按名字找到该类型；嵌套对象已展开为带路径的字段。
3. 记号：`?` = 可选字段；`arr[].field` = 数组元素字段；`obj.field` = 嵌套
   对象字段；`?.field` = 其父级可选字段存在后才有该子字段；联合类型原样
   展示。

示例（`CheckpointPreview`）：`changes[].kind` 表示数组元素上的 `kind`
字段；`context.targetJournalOffset` 表示嵌套对象 `context` 的字段。

## 2. 约定

- 表只含从 SDK 参数与返回类型可达的类型；添加或重命名类型字段后重跑
  `npm run docs:api-reference` 即自动更新。
- 内建泛型（`Record<string, unknown>` 等）与具名类型引用原样展示；具名
  类型的自身字段在它自己的行展开。
- 事件联合家族（`RuntimeEvent`/`RuntimeEventData`）不在此重复——见
  api-reference 的事件字典。
